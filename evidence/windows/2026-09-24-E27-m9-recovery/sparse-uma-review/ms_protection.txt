## D3DDDIGPUVIRTUALADDRESS_PROTECTION_TYPE structure

### Declaration

`d3dukmdt.h` line 1525, WDK 10.0.26100:

```c
typedef struct _D3DDDIGPUVIRTUALADDRESS_PROTECTION_TYPE
{
    union
    {
        struct
        {
            UINT64 Write            : 1;
            UINT64 Execute          : 1;
            UINT64 Zero             : 1;
            UINT64 NoAccess         : 1;
            UINT64 SystemUseOnly    : 1;    // Should not be set by the UMD
            UINT64 Reserved         : 59;
        };
        D3DKMT_ALIGN64 UINT64 Value;
    };
} D3DDDIGPUVIRTUALADDRESS_PROTECTION_TYPE;
```

### Description

The **D3DDDIGPUVIRTUALADDRESS_PROTECTION_TYPE** structure specifies the protection on the GPU virtual address that is mapped.

### Struct fields

#### Field Write

The pages will be allowed read-write access.

#### Field Execute

The pages will be allowed execute access.

#### Field Zero

The pages will be put to the *Zero* state ([**hAllocation**](#ns-d3dukmdt-d3dddi_mapgpuvirtualaddress) must be NULL). Reads return zero and writes are discarded in this state.

#### Field NoAccess

The pages will be put to the *Invalid* state ([**hAllocation**](#ns-d3dukmdt-d3dddi_mapgpuvirtualaddress) must be NULL).

#### Field SystemUseOnly

This member is for system use only and should not be set by the user-mode driver.
