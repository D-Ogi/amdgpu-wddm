addresses and stay); lab-ipv4 = lab network address; uuid = UUID; edid-blob-lines = hex lines of an
EDID blob; monitor-name = monitor name decoded from the EDID; lab-host-name = Windows host name;
dev-pc-path = development PC path with its user name;
camera-file-line = name of a camera frame file (the frames stay outside the repository).
