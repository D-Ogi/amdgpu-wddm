# Contributing

Read `CLAUDE.md` (working rules) and `docs/01-evidence-rules.md` first. The short version: no hand-typed register offsets, no hardware claims without evidence, measurements before theories.

## What is especially welcome

- Runs of the diagnostic USB on other BC-250 units (different BIOS versions), added under `evidence/` following the rules there.
- Corrections to `docs/facts.md` backed by evidence.
