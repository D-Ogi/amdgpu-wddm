# Nagi (amdgpu-wddm) 0.7.216.104-lab.c59bd190

A lab build of Nagi (amdgpu-wddm), an experimental Windows 11 x64 driver for the GPU of the ASRock BC-250. It is
not a tester release. It exists for two lab experiments on unit A before 0.7.216.104-tester.32 ships, and only the
lab flavour of it is built. It carries the content of tester.32 plus the two changes below.

It is signed with our **test certificate** and requires Windows test-signing mode.

## How to install

Unpack the zip file and double-click `setup.exe` in the folder it makes. It installs over tester.31v3 and over the
tester.32 release candidate. Windows reports the driver package version as 40.7.216.104.

## New

- **Large pages in video memory (experiment, off by default).** The setting `LargePages` selects how the driver
  maps video memory: 0 maps it in 4 KB pages (the default and the behaviour of tester.32), 2 lays the memory out for
  large pages but still maps 4 KB pages (the control arm), and 1 maps 2 MB and 1 GB pages where an allocation
  allows it. The driver log reports the pages it mapped. A change applies after the next restart of Windows.

## Fixed

- **Settings outside the catalog read as zero.** A driver setting that the settings catalog did not list read as 0
  instead of its default. The start logo was never drawn and the lab diagnostics switch did nothing. The driver now
  reads the default of every setting it uses, and a build check refuses a setting the catalog does not know (BD-190).

## Known issues

- Those of 0.7.216.104-tester.32. This build adds the `LargePages` experiment on top; a value other than 0 is for
  the lab measurement and may leave a game without a picture. Set it back to 0 and restart Windows.

## Settings affected

- `LargePages` (new, default 0).
- `BootLogo` and `LabDiagnostics` now read their defaults (1 and 0) instead of 0.
