# Pending release-notes lines: complete driver log lines (KMD 0.7.208.1)

This file is not a release. It holds the tester-facing lines for the next tester release notes. The release
step copies the lines into `docs/testing/release-notes/<version>-tester.N.md` and deletes this file.

## Fixed

- The driver log keeps 159 characters in a line. Five of the summary lines the driver writes at the end of a
  run were longer than that, so the last numbers of each line were cut off. One of them held the reasons why
  the driver refused to put a game's own picture on the screen, which is the first thing a support report
  needs for that problem. Each of these five lines is now two shorter lines, and no number is lost. The
  numbers themselves, the driver's behaviour and every setting stay as they were in version 0.7.207.1.

- The driver can set the automatic GPU clock aside after a start it must not repeat. It now writes the reason
  for that act next to the setting (`DpmClosedReason`) and keeps it until somebody asks for the automatic clock
  again. Before this version the reason was lost at the next start.

## Lines that need the installer half of BD-069

The installer half is a separate change (`tools/release/installer/common.ps1`, `$script:DriverClosures`, branch
`bd069-repair-closures`). It is not in this branch. The release step keeps the line below only in a release that
holds both halves, and drops it from a release that holds the driver alone. Without the installer half the
installer still reads the base clock as the tester's own choice, and `install.cmd -Repair` leaves it as it is.

- The installer no longer reads the base clock as your own choice after the driver sets the automatic clock
  aside. It names the driver's act in its report, and `install.cmd -Repair` brings the automatic clock back and
  removes the record.

## Known behaviour

- A support report from this version holds more log lines than one from 0.7.207.1, because five lines became
  ten. The log keeps the same number of lines in total, so a very long run now wraps a little earlier.
