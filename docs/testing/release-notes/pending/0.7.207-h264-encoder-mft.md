# Pending release-notes lines: the H.264 video encoder (M15.11)

This file is not a release. It holds the tester-facing lines for the next tester release notes of the b18
train. The release step copies these lines into `docs/testing/release-notes/<version>.md` and removes this
file.

## New

- The package installs an H.264 video encoder that runs on the GPU. Windows calls it a Media Foundation
  transform. A program that records the screen or a camera can now make H.264 video with the GPU of the
  BC-250. Game Bar, the Camera application and a Chromium browser find the encoder themselves. The installer
  puts `amdgpu_wddm_mft_h264.dll` in the `mft` folder of the install folder. Then it writes the registry keys
  that Windows needs to find the encoder.
- The uninstaller removes those registry keys and that file. A repair of a release that does not have the
  encoder also removes them.

## Known issues

- We did not test an application with this encoder on the BC-250 before this release. We tested only the
  encoder itself, with our own test program.
- The encoder tells Windows two things: that it is a hardware encoder, and that it gives its frames back
  asynchronously. Windows can therefore give the encoder to a program that asks for any asynchronous encoder.
  It does not give it only to a program that asks for a hardware encoder.
- If a program records worse video than before, or does not record at all, send us the support report. We can
  make a release that does not install the encoder.

## Settings affected

- None. The encoder has no setting in the control application. Each release decides if the installer writes
  the registry keys of the encoder.
