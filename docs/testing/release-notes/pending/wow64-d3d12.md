# Pending release-notes lines: 32-bit Direct3D 12 driver (WoW64)

This file is not a release. It holds the tester-facing lines for the next tester release notes. The change is on
branch `umd/wow64-d3d12`. The release step copies the lines into `docs/testing/release-notes/<version>-tester.N.md`
and deletes this file.

## New

- 32-bit Direct3D 12 programs now get our driver. The package has 32-bit builds of the Direct3D 12 driver, its
  engine and its Vulkan driver in the folder `wow64\d3d12`.
- 32-bit Direct3D 9 programs now get a GPU device. They use D3D9On12 on the 32-bit Direct3D 12 driver, as 64-bit
  Direct3D 9 programs do.

## Known issues

- The 32-bit Direct3D 12 driver has not run on the lab computer yet. On a computer without a BC-250 it reports the
  same capabilities as the 64-bit driver (feature level 12_1).

## Settings affected

- The installer writes a fourth entry (the Direct3D 12 entry) into `UserModeDriverNameWow` in the GPU's software
  key. It names `wow64\d3d12\amdgpu_wddm_d3d12.dll`. `verify.cmd` checks it (line `32-bit D3D/Vulkan`). The change
  has an effect after the restart that the install asks for.
- The 32-bit driver reads the same application profiles as the 64-bit driver
  (`HKLM\SOFTWARE\amdgpu-wddm\D3D12\Applications`).
