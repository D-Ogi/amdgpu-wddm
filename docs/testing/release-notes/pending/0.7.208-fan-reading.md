# Pending release-notes lines: the case fan reading (KMD 0.7.208.1)

This file is not a release. It holds the tester-facing lines for the next tester release notes. The release
step copies these lines into `docs/testing/release-notes/<version>-tester.N.md` and deletes this file.

## New

- The driver can read the board's own fan controller: the fan speed in revolutions per minute, the fan power
  in percent, and the temperature the board measures on the processor. The driver only reads these values. It
  does not set the fan speed. The board keeps the fan curve it had, and the BIOS "Fan Setting" option works as
  before.
- This reading is off until you turn it on, because another monitoring program can use the same hardware at
  the same time and both readings then become wrong. Close HWiNFO, Open Hardware Monitor, AIDA64, MSI
  Afterburner or a similar tool first. Then set `EnableHwmon` to 1 in the driver parameters and restart
  Windows. The driver reads the parameter when it starts.
- The support report carries the fan values when the reading is on. The report says `no reading` and the
  reason when it is off, when the fan controller did not answer, or when the newest value is too old.
- The kernel-mode driver is version 0.7.208.1.
