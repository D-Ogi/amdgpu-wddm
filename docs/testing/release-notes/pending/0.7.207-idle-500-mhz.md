# Pending release-notes lines: the idle GPU clock (KMD 0.7.207.1)

This file is not a release. It holds the tester-facing lines for the next tester release notes of the b18
train. The train's driver is one revision, 0.7.207.1, and it carries two more changes, which have their own
file in this directory (`0.7.207-kmd-train-b18.md`): a game's own picture on the screen without a copy, and
one-byte-per-pixel shared images for DirectComposition. The release step copies the lines of both files into
`docs/testing/release-notes/<version>-tester.N.md` and deletes them.

## New

- When the GPU has no work for 3 seconds, the driver sets the GPU clock to 500 MHz at the same voltage as at
  1000 MHz. The clock returns to 1000 MHz or more at the first work the GPU gets. The driver needs one measurement
  period and one clock change for this, which is some 25 to 35 milliseconds. A game or an application therefore
  starts at the normal clock. Work on the graphics engine and work on the copy engine both count, and a desktop
  that repaints a window now and then keeps the idle clock. The driver does not use the idle clock while a
  temperature limit, a measurement tool or a clock floor holds the clock, and it does not use it at all in the
  fixed-clock mode. If the GPU does not accept 500 MHz, the driver tries 800 MHz, and then stays at 1000 MHz.
- The kernel-mode driver is version 0.7.207.1.
