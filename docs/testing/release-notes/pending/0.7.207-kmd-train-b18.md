# Pending release-notes lines: the b18 train driver (KMD 0.7.207.1)

This file is not a release. It holds the tester-facing lines for the next tester release notes. The release
step copies the lines into `docs/testing/release-notes/<version>-tester.N.md` and deletes this file.

The kernel-mode driver of the b18 train is one revision, 0.7.207.1, and it carries three changes that were
written apart. The idle clock has its own file in this directory
(`0.7.207-idle-500-mhz.md`). The two changes below are the rest of the same driver.

## New

- A game can now put its own image on the screen directly, without the desktop compositor copying it first.
  The driver accepts the game's picture for the display hardware when the picture has the size, the layout and
  the colour format of the current screen mode, and when it is in graphics memory. The driver refuses every
  other picture, and the screen keeps the picture it has. The driver counts each refusal and names its reason in the driver
  log, so a support report says why a game did not get the direct path. Today only an application that asks for
  the path gets it, and the shipped applications ask for it only when you turn the experiment on, so the
  behaviour of a normal game does not change yet.
- Task Manager and other applications that use DirectComposition can now share a one-byte-per-pixel image with
  the driver. Before this, the driver refused that format and such an application lost its graphics device and
  had to build a new one. This was most visible as Task Manager's own graphs.

## Known behaviour

- The direct path is for a game in fullscreen or borderless mode. The desktop compositor decides for a
  borderless window, so the path is not guaranteed there.

## If something goes wrong

- The support report holds the driver log, which names the direct path's refusals and whether the path is on.
- An administrator can turn the direct path off: set the value `EnableScanoutAdmit` to 0 under the driver's
  `Parameters` key and restart the computer. The driver then behaves as version 0.7.205.1 did.
