## New

- When the GPU has no work for 3 seconds, the driver sets the GPU clock to 500 MHz at the same voltage as at
  1000 MHz. The clock returns to 1000 MHz or more at the first work the GPU gets, within about 30 milliseconds. A
  game or an application therefore starts at the normal clock. The driver does not use the idle clock while a
  temperature limit, a measurement tool or a clock floor holds the clock. If the GPU does not accept 500 MHz, the
  driver tries 800 MHz, and then stays at 1000 MHz.
- The kernel-mode driver is version 0.7.206.2.
