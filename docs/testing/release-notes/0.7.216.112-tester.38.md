# Nagi (amdgpu-wddm) 0.7.216.112-tester.38

A tester release of Nagi (amdgpu-wddm), an experimental Windows 11 x64 driver for the GPU of the ASRock BC-250. It
replaces 0.7.216.109-tester.37.

It is signed with our **test certificate** and still requires Windows test-signing mode.

## How to install

In Nagi Control App, open the Driver page and select **Install update**. Or run
`amdgpu-wddm-setup-0.7.216.112-tester.38.exe`, or `setup.exe` from the zip. You can install over tester.37 or
tester.36. The setup keeps your settings. Windows shows the package version as 40.7.216.112.

## New

- **Fewer `0x116` stops.** The driver now resets only the hung compute, graphics or copy queue when it can. The
  application loses its device, and Windows continues. [BD-180]
- **WDDM 2.9.** Windows can put game frames on an overlay plane (multiplane overlay). To go back to WDDM 2.0, run
  `bc250kmd_cli state set WddmVersionCap 0x2000` as administrator and restart. [BD-307]
- **The sign-in screen, the lock screen and the UAC prompt use the GPU.**
- **Nagi Control App in Portuguese (Brazil) and Spanish.**
- **The driver starts when no monitor is on at power-on.** Games and compute work. For a picture, switch the
  monitor on and restart Windows. [BD-341]
- **Game logs name the loaded graphics modules and the first faults of the game.** [BD-332]
- **Hibernation continues when the GPU cannot finish its work.** Not yet tested on a BC-250. [BD-188]
- Internal: FSR 4 support comes from a table row for each GPU [BD-332], and the driver can describe two overlay
  planes for video [BD-223]. You see no change.

## Fixed

Games and benchmarks:

- GTA V Enhanced: the cause of the failed start is fixed. Not tested with the game - please report. [BD-331]
- Unigine Heaven (32-bit, Direct3D 11) no longer runs out of memory. [BD-210, BD-352]
- 3DMark SystemInfo no longer crashes when 3DMark starts. [BD-347, BD-351]
- The GPU clock goes up under sustained load, and faster on a warm board. [BD-329, BD-336]
- YUV video swap chains in browsers and media players no longer remove the Direct3D device. [BD-333, BD-330]
- Direct3D 11 applications give offered memory back to Windows. [BD-309, BD-308]
- Direct3D 11 shader compiles on worker threads no longer run a second time. [BD-327]
- Vulkan programs no longer fill `%TEMP%` with shader files. [BD-211]
- Vulkan: buffer copies stay inside their source, and waits for submitted work return sooner. [BD-290, BD-200]

Screen and desktop:

- The monitor comes back after a DisplayPort re-plug. [BD-195]
- The desktop on the processor route shows its windows again. [BD-292, BD-296]
- Windows that scroll their own content are drawn by the GPU. [BD-306]
- Three starts with the monitor off no longer stop the driver with Code 43. [BD-343]

Installer and Nagi Control App:

- An install that stopped half-way no longer blocks other setups. [BD-298]
- The check after an install no longer waits five minutes after a clock step, and shows only the final
  result. [BD-335, BD-359]
- The Settings page fits in English. [BD-291]

Processor and power:

- The processor temperature limit goes in at every start and stays after a failed power change. [BD-297, BD-293]
- Processor settings go back to their start values after a driver restart inside one Windows session. [BD-295]
- The GPU finishes its work before hibernation. [BD-188]

Other:

- Game logs no longer show Windows debug messages as faults. [BD-344]
- Per-application settings work for programs with a path longer than 260 characters. [BD-256]
- Driver unload leaves no lock behind. [BD-315]
- A failed allocation open now fails, so frames no longer disappear. [BD-205]

## Known issues

- Keep the monitor on at power-on. If it was off, switch it on and restart Windows. [BD-341]
- A warm restart can, rarely, stop at a black screen. Switch the power off and on. [BD-145]
- A GPU fault in one Direct3D 12 program can still stop Windows with `0x116`. [BD-361]
- Rise of the Tomb Raider ended at the start of its benchmark in one run of six. Start it again. [BD-364]
- Unigine Heaven scores about 16 % lower than in October (86 against 102 frames per second).
- 3DMark Speed Way and Port Royal are not verified. [BD-339, BD-340]
- 3DMark: Windows can record a memory warning [BD-348], and the launcher can show a white window at some
  widths [BD-338].
- With the small VRAM setting, a heavy benchmark can restart the desktop once. [BD-337]
- Tear lines with vertical sync off in exclusive full screen. [BD-354]
- A 32-bit Direct3D 12 program can, rarely, stop at its first shader compile. Start it again. [BD-215]
- The processor can go 2 to 3 C above its temperature limit under a GPU load. Set the limit 3 C lower. [BD-349]
- Long sessions at 2000 MHz need good cooling. If the board gets hot, set the graphics clock limit to 1800 MHz.
- Video on a hardware overlay plane is not enabled. [BD-223]
- Restart Windows after every driver change, or the processor can stay slow. [BD-093]
- Games with kernel anti-cheat or module checks (for example Counter-Strike 2) do not start in test mode. [BD-160]
- A program that starts from a path longer than 260 characters can stop at once. Use a shorter path. [BD-256]
- Do not use hibernation: the first resume can stop Windows with `0x116`.
- Six diagnostic switches are removed from Nagi Control App. Stored values have no effect. [BD-361, BD-362]
- Please report blank taskbar or Start bars, with the time. [BD-282]

## Settings affected

- The installation keeps the settings that you changed.
- New setting `WddmVersionCap`: `0x2900` (WDDM 2.9, default) down to `0x2000` (WDDM 2.0), except 2.3. The driver
  reads it when it starts. [BD-307]

## Tested

On one BC-250, on the files of this release. All host tests of the build passed.

Windows 11 build 22631:

- Installation as an update, restarts, file hashes, three starts with the monitor off: passed.
- 3DMark: Time Spy 4450, Night Raid 25261, Steel Nomad 1121, Solar Bay 21027, Solar Bay Extreme 2135.
- Unigine Heaven (Direct3D 11): about 86 frames per second.
- Quake II RTX, two timedemo runs: about 67 frames per second.
- Rise of the Tomb Raider (DirectX 12): five complete runs of six, about 61 frames per second.

Windows 11 builds 26100, 26200 and 26300:

- Restarts, file hashes, the desktop on the GPU, one Direct3D 11 test and one Direct3D 12 test: passed.
- Update on 26300, new installation after an uninstall on 26200. On 26100 the release was installed before the run.
- The games did not run on these builds.

The numbers are information, not acceptance limits. The fan was at 100 %.
