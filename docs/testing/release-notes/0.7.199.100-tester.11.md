# amdgpu-wddm 0.7.199.100-tester.11

A tester release of amdgpu-wddm, an experimental Windows 11 x64 driver for the GPU of the ASRock BC-250. It is for
people who want to test the driver on their own BC-250 and report what happens. It is not ready for daily use.

## New

- Driver updates and changes of the desktop route take effect at the next restart of Windows. The installer and the
  control application never stop or restart the desktop compositor (DWM) while you are logged on.
- The kernel-mode driver is version 0.7.199.1.
- `verify.cmd` reports when it saw the desktop compositor replaced in your current Windows session.
- An installation without internet (`install.cmd -FirmwareDir <folder>`) keeps the folder and your other options
  across all restarts of the installation.

## Fixed

- Some Windows 11 apps (the command bar of File Explorer, Task Manager) could ignore mouse clicks after an
  installation or a change of the desktop route, because the desktop compositor was restarted under the running
  desktop. The installer no longer restarts it; the change waits for the next restart of Windows.

## Known issues

- After a crash or a power loss the driver closes the GPU desktop path and the desktop is drawn by the CPU (slower
  animations). "Reopen the GPU desktop path" on the Recovery page of amdgpu-wddm Control opens it again.
- Direct3D 11 applications and games run on the CPU (software rendering), so they are slow. Use the Direct3D 12 mode
  of a game if it has one.
- 32-bit applications do not have a driver yet.
- Secure Boot must be off, and Windows runs in test mode ("Test Mode" shows on the desktop), because the driver is
  signed with a test certificate.
- The installation needs internet access for the AMD GPU firmware, or a folder with the firmware files
  (`INSTALL.md`, section "GPU firmware").
- The Microsoft Visual C++ 2015-2022 Redistributable (x64) must be installed.
- After each logon, a small blue window confirms the driver start for about one minute. Do not close it.

## Settings affected

- The settings you changed are kept. A setting that you did not change gets the new default of this release.
- The installer shows each setting it changes before it changes anything.
