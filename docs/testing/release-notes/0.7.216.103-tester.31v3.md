# Nagi (amdgpu-wddm) 0.7.216.103-tester.31v3

A tester release of Nagi (amdgpu-wddm), an experimental Windows 11 x64 driver for the GPU of the ASRock BC-250. It
replaces 0.7.216.102-tester.31v2. The notes of 0.7.216.102-tester.31 and 0.7.216.102-tester.31v2 also apply to this
release.

It is signed with our **test certificate** and still requires Windows test-signing mode.

## How to install

Copy `amdgpu-wddm-setup-0.7.216.103-tester.31v3.exe` to a local folder and double-click it. Or unpack the zip file
and double-click `setup.exe` in the folder it makes. You can install this release over tester.31 or tester.31v2: you
do not have to uninstall first. Windows reports the driver package version as 40.7.216.103, which is higher than
40.7.216.102 of tester.31v2.

## New

- When Smart App Control blocks the installation, the setup window shows how to turn it off, with pictures.

## Fixed

- **The monitor stayed black after you disconnected it and connected it again**, on DisplayPort and through a
  passive DisplayPort-to-HDMI adapter, also when you changed from one to the other. Only a restart helped.
- **Windows Security made the desktop flicker** on Windows 11 24H2 and later. It now draws on the processor.

## Known issues

- **Update from tester.31 or tester.31v2 on Windows 11 24H2 or later:** until the update is complete, the old driver
  is still installed, and Windows Security can make the desktop flicker again. The Smart App Control button of the
  setup window opens Windows Security. Before you start the setup, open PowerShell as administrator and run:

  ```powershell
  $k='HKLM:\SOFTWARE\amdgpu-wddm\AppRouter'; if (!(Test-Path $k)) { New-Item $k -Force | Out-Null }; $d=@((Get-ItemProperty $k -ErrorAction SilentlyContinue).Deny) + 'sechealthui.exe' | ? { $_ } | Select-Object -Unique; New-ItemProperty $k -Name Deny -PropertyType MultiString -Value $d -Force | Out-Null
  ```

  This adds Windows Security (`sechealthui.exe`) to the list of applications that always draw on the processor. It
  keeps the entries that are already in the list. It has an effect immediately, without a restart. To check it, run
  `reg query HKLM\SOFTWARE\amdgpu-wddm\AppRouter /v Deny`. After the update, you do not need the entry, because
  this release has it. If the desktop flickers already, close Windows Security (Alt+F4 or Task Manager).
- **Small, stretched desktop after the start:** some boards start the screen in a small scaled mode, for example
  800x600 on a 2560x1440 screen. The driver then keeps that one mode. To get the native resolution, open a command
  prompt as administrator, run `bcdedit /set {globalsettings} highestmode on` and restart the computer.
- A passive adapter that does not identify itself works only when it is connected at the start of Windows.
- Do not use hibernation: the first resume can crash Windows with `0x116`. Set the power button to "Shut down".

## Settings affected

- This release changes no setting and no default. The installation keeps the settings that you changed.

## Tested

On our BC-250 (Windows 11 23H2) with the kernel driver of this release: four disconnects and reconnects (DisplayPort,
the adapter, and both changes between them) gave the picture back each time, with no restart. Quake II RTX
completed both timedemos (60.4 FPS with the ray-tracing pipeline, 67.6 FPS with ray query).
