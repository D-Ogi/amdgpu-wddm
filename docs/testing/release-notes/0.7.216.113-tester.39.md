# Nagi (amdgpu-wddm) 0.7.216.113-tester.39

A tester release of Nagi (amdgpu-wddm), an experimental Windows 11 x64 driver for the GPU of the ASRock BC-250. It
replaces 0.7.216.112-tester.38.

It is signed with our **test certificate** and still requires Windows test-signing mode.

These notes are for the first candidate of tester.39. The list grows until the release.

## How to install

In Nagi Control App, open the Driver page and select **Install update**. Or run
`amdgpu-wddm-setup-0.7.216.113-tester.39.exe`, or `setup.exe` from the zip. You can install over tester.38 or
tester.37. The setup keeps your settings. Windows shows the package version as 40.7.216.113.

## New

- **Eight processor cores.** The driver can start the two cores that the firmware keeps off. Nagi Control App
  shows the core count on the core card and tells you which restart a stored count needs. [BD-368]
- **Direct3D 11 offers the WDDM 2.9 interface** when the kernel driver runs as WDDM 2.9. [BD-371]
- **Shared Direct3D 11 resources between processes.** A program can open a resource that a different program
  made. [BD-373]
- **Direct3D 11 resources appear in the Windows UMD logging events.** [BD-373]

## Fixed

- Direct3D 11 applications release the memory of an offered resource when Windows lets them. [BD-372]
- Direct3D 11 applications learn when the memory of an offered resource was released. [BD-372]
- The kept processor settings stay after an orderly end of Windows. [BD-369]
- The picture on the processor route is complete after a restart. [BD-369]
- `bc250kmd_cli` shows "no clock" for a metrics table that has no clock. [BD-368]

## Known issues

- Direct3D 12 cannot open a shared resource that Direct3D 11 made. [BD-373]
- The effect of the 1 MiB limit for dedicated Direct3D 11 buffers on games is not measured. [BD-374]
- The known issues of tester.38 stay in force.

## Settings affected

- The installation keeps the settings that you changed.
- The stored processor core count goes in at the restart that the core card names. [BD-368]
