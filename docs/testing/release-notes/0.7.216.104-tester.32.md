# Nagi (amdgpu-wddm) 0.7.216.104-tester.32

A tester release of Nagi (amdgpu-wddm), an experimental Windows 11 x64 driver for the GPU of the ASRock BC-250. It
replaces 0.7.216.103-tester.31v3.

It is signed with our **test certificate** and still requires Windows test-signing mode.

## How to install

Copy `amdgpu-wddm-setup-0.7.216.104-tester.32.exe` to a local folder and double-click it. Or unpack the zip file
and double-click `setup.exe` in the folder it makes. You can install this release over tester.31, tester.31v2 or
tester.31v3: you do not have to uninstall first. Windows reports the driver package version as 40.7.216.104, which
is higher than 40.7.216.103 of tester.31v3.

## New

- **Vulkan games use Fast (flip) again by default.** In full screen, the frames of a Vulkan game go directly to the
  screen. The control app offers the setting "Vulkan presentation" again, for all games at once. If a Vulkan game
  shows a black or frozen picture, choose "Compatible" there.
- **The control app tells you when the driver changed to its safe settings.** When Windows stopped unexpectedly
  while the graphics chip drew the desktop, the driver starts the next time with the desktop drawn by the processor
  and the graphics chip at its base speed. It stays like this until you change it. Before, nothing told you about
  it. Now the home page of the control app shows it, and one click turns all of it back on. The change applies
  after the next restart of Windows.
- **No more small blue window after the logon.** The "Nagi start check" window with its two-minute countdown is
  gone, and so is its setting in the control app. The driver now accepts its start on a desktop where nothing
  moves: it needs one new picture after the start and no picture that it did not show.

## Fixed

- **Code 43 and a black screen after a restart of the graphics device**, from tester.31 on. A change of the
  compute units in the control app also restarts the device. Only a restart of Windows helped.
- **32-bit Direct3D 11 games ran out of memory.** Unigine Heaven 4.0 stopped with "out of memory" after about four
  minutes. The driver now gives a 32-bit program more of its memory space.
- **Shader compiles became slower and slower** over the weeks. Each compile left a file `MEMxxxx.TMP` in the
  temporary folder, and when there were very many of them, each compile took seconds. The driver no longer leaves
  these files, and the installation removes the old ones (files older than one day).
- **GOG Galaxy stopped responding after the login.**
- In rare cases, the Vulkan part of the driver released graphics memory while the graphics chip could still use it.
  This could cause a GPU fault.

## Known issues

- **Update from tester.31 or tester.31v2 on Windows 11 24H2 or later:** until the update is complete, the old driver
  is still installed, and Windows Security can make the desktop flicker. The Smart App Control button of the setup
  window opens Windows Security. Before you start the setup, open PowerShell as administrator and run:

  ```powershell
  $k='HKLM:\SOFTWARE\amdgpu-wddm\AppRouter'; if (!(Test-Path $k)) { New-Item $k -Force | Out-Null }; $d=@((Get-ItemProperty $k -ErrorAction SilentlyContinue).Deny) + 'sechealthui.exe' | ? { $_ } | Select-Object -Unique; New-ItemProperty $k -Name Deny -PropertyType MultiString -Value $d -Force | Out-Null
  ```

  This adds Windows Security (`sechealthui.exe`) to the list of applications that always draw on the processor. It
  keeps the entries that are already in the list. It has an effect immediately, without a restart. An update from
  tester.31v3 does not need it.
- **Small, stretched desktop after the start:** some boards start the screen in a small scaled mode, for example
  800x600 on a 2560x1440 screen. The driver then keeps that one mode. To get the native resolution, open a command
  prompt as administrator, run `bcdedit /set {globalsettings} highestmode on` and restart the computer.
- A passive adapter that does not identify itself works only when it is connected at the start of Windows.
- Do not use hibernation: the first resume can crash Windows with `0x116`. Set the power button to "Shut down".

## Settings affected

- **Vulkan presentation:** the default is now "Fast (flip)". If you chose "Compatible" in an earlier release, it
  stays "Compatible".
- The installation keeps the other settings that you changed.

## Tested

On our BC-250 (Windows 11 23H2), each fix with the build that carries it: two restarts of the graphics device in one
boot and a start in the small scaled mode gave the picture back each time, with no Code 43. Unigine Heaven 4.0
(32-bit, Direct3D 11) completed its benchmark at 102.3 FPS. Quake II RTX with Fast (flip) went directly to the screen
in full screen and in a borderless window, at 101.8 to 104.5 FPS.
