# amdgpu-wddm 0.7.216.100-tester.19

A tester release of amdgpu-wddm, an experimental Windows 11 x64 driver for the GPU of the ASRock BC-250. It is for
people who want to test the driver on their own BC-250 and report what happens. It is not ready for daily use.

The kernel-mode driver, the installer and amdgpu-wddm Control of this release belong together. Install the three of
them from this package, and do not mix them with the files of another release. The kernel driver writes a record that
only this installer and this control program read.

The release before this one is 0.7.215.100-tester.18. This release replaces it. The notes of 0.7.215.100-tester.18
list the changes since 0.7.213.102-tester.17, and they apply to this release too, with the changes below.

## New

- DisplayPort audio now plays sound. The driver starts the audio stream of the DisplayPort output, so Windows can
  send sound to the speakers of your monitor. This is new in this release. Tell us if you hear the sound or not.
- The processor cards of "Advanced tuning" now work by default. The setting `CpuTune` is 1 after the installation.
  Each change is still a trial: the driver takes it back by itself, unless you keep it.
- amdgpu-wddm Control is version 0.6.0.0. The support report now shows a different number than the program of
  0.7.213.102-tester.17.
- The kernel-mode driver is version 0.7.216.1.

## Changed

- The Driver curve of the case fan now turns the fan at full speed from 80 C. In 0.7.215.100-tester.18 it did this
  from 85 C. The new curve is 40 C 50 %, 60 C 70 %, 70 C 85 %, 76 C 95 % and 80 C 100 %. It still turns the fan at
  least as fast as the BIOS "Standard Mode" curve. The Quiet and Performance curves did not change.

## Fixed

- YouTube and other video in Edge play at their normal speed again. With 0.7.215.100-tester.18, Windows showed a
  "Digital Audio (HDMI)" device that had no audio clock. Then no sound came out, and video played at about 0.7 times
  its speed. The driver now shows this device only while its audio stream runs.
- After a fan test, the fan goes back to the mode that you selected. With 0.7.215.100-tester.18, the fan went back to
  the board's own curve after each test, also when you selected another mode.
- Home no longer asks you to confirm a start that the logon task already confirmed.

## Known issues

- We did not listen to the DisplayPort sound on the BC-250 yet. The audio stream passed our tests on a computer
  without a BC-250 only.
- The known issues of 0.7.215.100-tester.18 apply, except the one about DisplayPort audio.

## Settings affected

- The installation keeps the settings that you changed. A setting that you did not change gets the new default of
  this release.
- `CpuTune` is a new default: 1. 0 makes the processor cards read-only again. Write 0 and restart Windows to go back.
- `EnableDpAudioStream` is a new `REG_DWORD` value under the driver service's `Parameters` key. 1 is the default.
  1 starts the DisplayPort audio stream. 0 means that the driver does not prepare the DisplayPort audio device at
  all, and Windows shows no DisplayPort audio device. Write 0 and restart Windows to go back.
- `EnableDpAudio` 0 still means that the driver does nothing for audio. `EnableDpAudioEndpoint` 0 now has the same
  effect as `EnableDpAudioStream` 0.

## If something goes wrong

- If the sound or the video is wrong, write 0 into `EnableDpAudio` and restart Windows. Then tell us what happened.
- If the fan does not behave as you expect, select Automatic on the Case fan card. The board then runs the fan with
  its own curve. If that does not help, write 0 into `EnableFanControl` and restart Windows.
- Send us the support report from amdgpu-wddm Control. It holds the driver log and the fan control line.
