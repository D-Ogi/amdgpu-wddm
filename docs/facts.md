# Facts

The only list of established facts in this project. Rules and statuses: [`01-evidence-rules.md`](01-evidence-rules.md). Nothing is `MEASURED` or `CONFIRMED` without hardware evidence in `evidence/`.

Facts are kept as a graph in [`facts/data/`](facts/data/), one YAML file per area. This page and every page under [`facts/`](facts/) are generated from it; format, edges and area borders: [`facts/README.md`](facts/README.md).

## Adding a fact

1. `python tools/facts/gen_facts.py next-id` prints the next free ID.
2. Append the fact, with its edges to the facts it uses, supports, refutes or supersedes, to its area file in [`facts/data/`](facts/data/). That is the only file you edit.
3. `python tools/facts/gen_facts.py --write` regenerates the pages; commit them with the data file. `--check` (in `tools/quality/quick.ps1` and CI) fails when this step was forgotten.

Correct a fact in place and link the newer one to it (`supersedes` or `refutes`); never append a second version. IDs are never reused or renumbered.
