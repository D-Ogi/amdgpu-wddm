# Agent instructions

Read and follow [CLAUDE.md](CLAUDE.md) before working in this repository. It is the single source of
engineering rules, hardware constraints, evidence requirements and project direction for every agent,
whatever its name. Read [docs/01-evidence-rules.md](docs/01-evidence-rules.md) before the first change.

Do not copy rules into this file: add or change them in CLAUDE.md, so the two never drift apart.
